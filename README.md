# anthrax

Anthrax is a Fabric client mod. Gameplay features are grouped under `modules/` and
the custom interface is under `gui/`.

Module enable states, module settings, and GUI theme/effects preferences are saved
to `config/anthrax.properties`. Loadout Manager inventory presets are saved separately
to `config/anthrax-loadouts.properties`. One-shot actions and in-progress game actions
are not resumed after restarting Minecraft.

## Setup

For setup instructions, please see the [Fabric Documentation page](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up) related to the IDE that you are using.
